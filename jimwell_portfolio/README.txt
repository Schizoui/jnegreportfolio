BEFORE PUBLISHING
1. Open index.html in a browser and review every section.
2. Replace YOUR-EMAIL@example.com with your professional email address.
3. Confirm the job dates, job titles, school/program wording, and responsibilities.
4. Add a professional photo only if you want one. Do not publish private phone/address details unless you intend to share them.

PRIVACY: LINK-ONLY + PASSWORD
The included website is the portfolio itself. It does NOT implement secure password protection.
Do not add a password using only front-end JavaScript: that can be bypassed and the page source can expose it.

For genuine password/access control, publish the site privately behind an access-control layer (for example, Cloudflare Access in front of a Cloudflare Pages site). Configure an email allowlist or one-time PIN login for the people you invite. If you specifically want one shared password, choose a hosting provider/plan that offers server-side password protection. A hard-to-guess URL alone is not equivalent to a password.
